# Datament documentation instructions

Read `.mintlify/AGENTS.md` before any documentation change. It is the shared policy
for Codex, Claude Code and Mintlify agents working in this repository.

- This is the Datament / IN IDEAS knowledge base, built with Mintlify.
- Pages use MDX; navigation and configuration are in `docs.json`.
- Use active voice, concise sentences and sentence-case headings.
- Preserve existing pages and links when adding a dated change record.
- Open documentation PRs for review; never automatically merge or publish.
- The repository is public. Do not commit secrets or private operational evidence.

Before Mintlify automation, CI or publishing work, run `mint instructions automate`
or the relevant topic. If the CLI is unavailable, use `npx mint@latest instructions`.
Use the installed Mintlify skill and current official documentation for details.
